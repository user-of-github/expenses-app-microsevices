## Expenses app microservices | C++ & Node.js  

I've always wanted to develop some real-world-like REST-API-microservices app using modern C++ stack.
Here I developed simple, but full‑fledged, real application with Postgres, migrations (Liquibase), microservices (via Docker-compose), modern C++ 17/20 standard and REST frameworks - Drogon.cpp & Crow.cpp, DTOs, validations, error-handling, and of course some sort of CI/CD via GitHub Actions. And one service with Node.js (Ollama+Langchain+Fastify). First half developed manually, second - via OpenCode/Codex + Alibaba Cloud Model LLMs.
