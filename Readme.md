## Expenses-app microservices | C++ & Node.js & AI  

I've always wanted to develop some real-world-like REST-API-microservices app using modern C++ stack.  s
Here I developed simple, but full‑fledged, real application with 
- Postgres, 
- migrations (Liquibase), 
- microservices (via Docker-compose or Minikube), 
- modern C++ 17/20 standard and REST frameworks - Drogon.cpp & Crow.cpp, 
- Excel-reports generation, 
- DTOs, 
- validations, 
- error-handling, 
- and of course some sort of CI/CD via GitHub Actions. 
- And one service with Node.js - AI-assistant-agent. 

First half developed manually, second - via OpenCode/Codex + Alibaba Cloud LLMs.
